# Synthetic Water Network Asset Mapping Workflow

## Overview
This project demonstrates a GIS workflow for digitising and structuring water infrastructure assets using synthetic data. It reflects the type of work involved in utility asset mapping while avoiding the use of confidential employer data.

## Objective
To create a clean and consistent GIS representation of a synthetic water network, including pipes, valves, service lines, and meters, with an emphasis on layer structure, attribution, and map readability.

## Skills Demonstrated
- Utility asset digitisation
- GIS data structuring
- Layer design and symbology
- Attribute management
- QA/QC checks
- Map presentation

## Data
The dataset used in this project is fully synthetic and created for portfolio purposes. No real infrastructure records, coordinates, or employer data are included.

## Workflow
1. Designed a synthetic asset schema for pipes, valves, service lines, and meters.
2. Digitised a sample network layout.
3. Added attributes such as asset ID, asset type, status, and material.
4. Applied symbology and layer hierarchy for map readability.
5. Performed quality checks on geometry, connectivity, and attribute completeness.

## Output
The final output is a synthetic utility map that demonstrates how water infrastructure assets can be organised and visualised in a GIS environment.

## Notes
This project is inspired by real utility GIS workflows, but all data, counts, and map features are synthetic and created for demonstration only.
